# 🧮 Discount Calculator

A simple, interactive, and bilingual Python application designed to make discount calculations easier!

Whether you want to **calculate the discount percentage** or **find the final price after applying a discount**, this application has you covered. It supports two languages: **English and Indonesian (Bahasa Indonesia)**, making it accessible to more users.

## ✨ Features

- **Calculate Discount Percentage** — Find out how much discount you get based on the original price and the discounted price.
- **Calculate Final Price** — Calculate the final price of a product after applying a discount percentage.
- **Bilingual Support** — Switch between English and Indonesian.
- **Simple and User-Friendly** — Easy to use, even for beginners.
- **Python-Powered** — Built with Python as a practical project for learning and exploring programming.

## 🚀 Getting Started

Ready to calculate discounts the easy way?

### Prerequisites

Make sure you have Python installed on your computer.

You can check your Python installation by running:

```bash
python --version
```

### Installation & Usage

1. Clone this repository:


   git clone https://github.com/ArianzNava26/discountcalculator.git


2. Navigate to the project directory:


   cd discountcalculator


3. Run the application:

   python asking.py
   

**And from there, the magic begins! ✨**

Follow the instructions displayed in the terminal, choose your preferred language, and start calculating discounts.

## 🧠 What Can You Calculate?

### 1. Discount Percentage

Want to know how much discount a product offers?

For example:
- Original price: Rp100,000
- Discounted price: Rp75,000
- Discount: **25%**

### 2. Final Price After Discount

Want to know how much you need to pay after a discount?

For example:
- Original price: Rp200,000
- Discount: 30%
- Final price: **Rp140,000**
